# Michelle Gurovith Portfolio

A static resume and portfolio website for Michelle Gurovith, focused on software engineering experience, education, projects, technical skills, and resume download access.

## Preview Locally

From the project directory, run:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Project Structure

```text
.
├── index.html                  # Main portfolio and resume page
├── style.css                   # Site styling and responsive layout
├── scripts/script.js           # SoundCloud interaction for the music section
├── Michelle_Gurovith_SWE.pdf   # Downloadable resume
└── img/                        # Profile photos, icons, and flags
```

## Updating Content

- Edit `index.html` for resume text, experience, projects, education, skills, and links.
- Replace `Michelle_Gurovith_SWE.pdf` when the downloadable resume changes.
- Update images in `img/` if the profile photo or preview assets change.

## Deployment

Because this is a static site, it can be hosted on GitHub Pages, Netlify, Vercel, or any static web server.
